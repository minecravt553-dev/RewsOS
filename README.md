# RewsOS 🖥️

Виртуальная операционная система на Python в стиле Windows 11.
Работает в полноэкранном режиме через `tkinter`, обои генерируются пиксельно (Win11 Bloom), интерфейс — со сглаженными углами через Pillow.

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Возможности

- 🚀 **Загрузочный экран** — 5.5 секунд, затем рабочий стол
- 🖼️ **Обои Win11 Bloom** — генерируются попиксельно, без внешних файлов
- 📊 **Панель задач** — скруглённая, по центру внизу, как в Windows 11
- 🔵 **Кнопка «Пуск»** — квадрат со скруглением + иконка-окошко
- 🎬 **Анимация меню** — табличка выезжает из кнопки с ease-out
- 🟦 **Пункты меню** — сине-голубые, со сглаживанием и hover-эффектом
- 💻 **Терминал** — окно типа `cmd` с командами
- ⏰ **Часы** — в правом верхнем углу
- 🎨 **Сглаживание через суперсэмплинг** (Pillow, `SS=4`, `LANCZOS`)

## 📦 Установка

### 1. Требования

- **Python 3.9+**
- **tkinter** (обычно идёт в комплекте с Python)
- **Pillow**

Установка Pillow:

```bash
pip install pillow
```

### 2. Клонирование

```bash
git clone https://github.com/<ваш-username>/RewsOS.git
cd RewsOS
```

### 3. Запуск

```bash
python main.py
```

> Система откроется в **полноэкранном режиме**. Выход — клавиша **Esc**.

## 🛠️ Технические детали

### Сглаживание (антиалиасинг)

Все скруглённые фигуры рисуются через **Pillow** с коэффициентом суперсэмплинга `SS = 4`:

```python
SS = 4  # рендер в 4× разрешении, потом уменьшение через LANCZOS
```

Это даёт плавные края без зубцов даже на больших экранах. Можно увеличить до `8` или `16` — будет ещё глаже, но чуть медленнее.

### Обои

Обои **не берутся из системы**, а генерируются попиксельно по полярным координатам:

```python
WALLPAPER_PETALS = 7  # количество лепестков Bloom
WALLPAPER_SCALE  = 0.5  # масштаб рендера
```

### Углы без «полос»

Функция `rounded_on_wallpaper()` берёт **кусок обоев** под панелью/меню и накладывает на него скруглённую фигуру с прозрачными углами — поэтому углы идеально сливаются с обоями, без чёрных полос.
